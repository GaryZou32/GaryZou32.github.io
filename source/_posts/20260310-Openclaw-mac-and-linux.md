# OSI：
open systems interconnection model，7层，
1. 物理层 physical
2. 数据链路层 data link
3. 网络层 network
4. 传输层 transport
5. 会话层 session
6. 表示层 presentation
7. 应用层 application

一般被简化为：
Physical
Data Link
Network
Transport
Application

Application: Proxy; APP--Proxy--Internet

Transport: TCP(HTTPS, SSH, FTP); UDP

Network: IP routing, VPN working; my computer--VPN tunnel--VPN server--Internet\
